Accuracy constraints based on the implemented feature:
The agent gathers bounded resource metadata and presents findings, missing evidence, and next steps. Supported changes require an explicit user request, a specific target/parameter preview, user review and execution under current permissions. Agent inspection spans cluster health, topic metadata, consumer lag, connector status, streaming-job summaries, schema summaries, alerts and lineage. Agent mutation support is limited to selected topic, connector and consumer-offset operations; do not imply arbitrary changes to every ecosystem resource. The engine checks outcomes; uncertain outcomes can occur, so do not imply guaranteed success. The agent does not read Kafka message payloads, automatically repair systems, run arbitrary commands, operate unattended or guarantee root causes. Do not depict autonomous self-healing. The connected services do the streaming; the agent manages and investigates them.
The visible phrase "Verified outcomes & audit history" describes outcome verification and recording, never guaranteed success.

Kafka is allowed only as the product's ecosystem context. Keep exact branding "k-shui", "k-shui Agent", and "k-shui engine".
Render ONLY the specified visible copy, with accurate spelling and crisp text. No invented claims, no extra slogans, no implementation details, no watermarks. Make the agent unmistakably the hero and the engine unmistakably the controlled bridge to the ecosystem.
